# Agri-Water Risk Monitoring & Early Warning System

An AI-driven, sensorless water quality monitoring and crop disease detection platform built for smallholder farms and aquaculture.

## 🚀 Key Features
* **Sensorless Water Risk Scoring:** Uses open marine APIs and Random Forest ML models to calculate real-time toxicity and risk without expensive hardware.
* **AI Crop Disease Diagnosis:** Uses MobileNetV3 computer vision to diagnose crop and aquatic diseases from photos.
* **Instant Multilingual Alerts:** Automatically sends Kannada SMS and voice warnings to basic feature phones in under 3 minutes.
* **Cooperative Web Dashboard:** Built with Next.js to provide multi-pond analytics and historical trends for fishery cooperatives.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI
* **Frontend:** Next.js, Tailwind CSS
* **AI/ML:** Random Forest, MobileNetV3, Scikit-learn
* **Alerting:** Fast2SMS / Twilio API
